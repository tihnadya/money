# money
# 💰 Мани.точка

Приложение для учёта личных финансов. Работает полностью локально в браузере — данные никуда не отправляются.

---

## ⚠️ Где могут потеряться данные

Все данные хранятся в **localStorage браузера** под ключом `money_tochka`. В некоторых случаях браузер может их удалить — не по вине приложения, а по своим правилам.

### 🔴 Высокая вероятность

**1. Режим инкогнито**
В приватном режиме localStorage очищается при закрытии вкладки. Не ведите учёт в инкогнито.

**2. Очистка данных браузера**
Если очистить «Кэш», «Историю», «Данные сайтов» — данные удалятся.
👉 Добавьте сайт в исключения при очистке.

**3. Другое устройство или другой браузер**
localStorage привязан к конкретному браузеру на конкретном устройстве. На другом телефоне или в другом браузере данных не будет.
👉 Для переноса используйте **Настройки → 📤 Экспорт** и **📥 Импорт**.

**4. Переустановка браузера**
При удалении и переустановке браузера все данные сайтов стираются.

### 🟡 Средняя вероятность

**5. Переполнение localStorage**
Лимит около **5 МБ** (~400 000 записей о расходах, ~30 лет учёта). Для личного использования практически недостижимо.

**6. Аварийное закрытие браузера в момент сохранения**
Если браузер выключился ровно в момент записи, JSON может сохраниться обрезанным. Не закрывайте вкладку резко во время добавления расхода.

**7. Ручное изменение данных в консоли**
Если случайно испортить содержимое ключа `money_tochka` — приложение стартует с нулями.

---

## 📌 Главное правило

> **Раз в 1–2 недели нажимайте Настройки → 📤 Экспорт данных.**
> Файл `money_tochka_backup_ГГГГ-ММ-ДД.json` сохранится на устройстве.
> Если что-то случится — восстановите через 📥 Импорт за 5 секунд.
